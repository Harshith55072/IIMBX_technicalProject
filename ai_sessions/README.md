# AI session logs

Conversation logs of the AI-assisted development of this project (allowed by the brief).

- `01_claude_code_session_log.md` - lean, ordered log of the user / Claude (AI coding agent connected over MCP) collaboration. Snapshot of the repo-root `conversation_log.md`.
- `02_claude_ai_chat_export.md` - raw claude.ai chat (copy-pasted, converted to markdown with the message text left verbatim; only User/Claude headings added).

`project.md` in the repo root is the running context file that kept agents in sync between sessions.
