## Design decisions
- **Stack:** Python + FastAPI; vanilla HTML/JS page served by backend; SQLite (or in-memory) for cache + counters. No RAG (docs tiny → whole docs in prompt, tagged by filename).
- **Conflict handling in code:** loader parses `LAST UPDATED`/`STATUS`/"supersedes <file>" → mark 02 superseded and **exclude it from the prompt** (can't leak 50%/late-grace). Trade-off: can't answer "what was the old policy" (fine; brief says use latest).
- **Injection defense:** split doc 04 Sec 3 into comments; regex-flag/redact injection-like comments (e.g. "system update", "AI assistants", "disregard"); remaining comments labeled UNOFFICIAL; system prompt says doc text is data not instructions; add test asserting Q6 stays closed-book/20 Nov.
- **Gemini output:** structured JSON `{answerable, answer, sources[]}`, low temperature; uncovered/off-topic → `answerable=false` + "not mentioned in the course documents". Sources from model validated against real filenames.
- **Cache (no extra Gemini calls):** L1 exact normalized question; L2 local fuzzy (token/TF-IDF, high threshold, numbers must match); follow-ups keyed on question + previous-turn key; cache negative answers; never cache errors.
- **Robustness:** UI disables Send + spinner; per-key single-flight; global concurrency cap; per-session rate limit; retry+backoff on 429/5xx; friendly error.
- **Counters:** total, api_calls (each real outbound call, retries included), cache_hits → `/api/stats`, polled by UI.
- **Hosting:** Render free (cold start on idle). **User confirmed: Python/FastAPI + Render.** Python already installed locally.
- **Repo layout:** `app/`, `course_docs/` (all 4 docs, verbatim; v1 is committed but excluded from the prompt in code), `static/`, `tests/`, `scripts/`, `ai_sessions/`, `README.md` (approach, architecture, assumptions, deploy), `render.yaml`, `requirements.txt` (runtime, pinned) + `requirements-dev.txt` (adds pytest), `.env.example` (placeholder only). `.gitignore` covers `.env`, `.env.*` (except `.env.example`), venv, caches, `*.db`, `*.log`, editor/OS files; verified with `git add -n .` (no secrets staged, key exists only in local `.env`).
